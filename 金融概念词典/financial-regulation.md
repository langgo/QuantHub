# 金融监管

[← 返回目录](index.md)

## 官方解释
金融监管是监管机构对银行、证券、保险、基金等金融活动实施的规则和监督，以降低风险和保护投资者。

## 小白解释
金融监管就是给金融机构立规矩，防止乱加[杠杆](leverage.md)、乱卖产品、出事传染全市场。

## 示例
银行资本要求提高后，银行放贷扩张可能更谨慎，但系统稳定性提高。

## 与其它概念的关联作用
| 相关概念 | 详细关联与传导链路 |
|---|---|
| [银行挤兑](bank-run.md) | 金融监管变化若增加不确定性、违约压力或市场恐慌 → 投资者转向防守 → 银行挤兑的重要性上升，并可能反过来影响资产价格。 |
| [央行](central-bank.md) | 金融监管变化会影响市场对政策松紧的判断 → 投资者重新评估央行是否加息、降息或投放流动性 → 央行成为确认政策路径的关键变量。 |
| [信用利差](credit-spread.md) | 金融监管变化会改变通胀、增长或信用风险预期 → 债券买卖力量变化 → 信用利差随价格、收益率或风险补偿重新定价。 |
| [违约率](default-rate.md) | 金融监管变化会改变通胀、增长或信用风险预期 → 债券买卖力量变化 → 违约率随价格、收益率或风险补偿重新定价。 |
| [杠杆](leverage.md) | 金融监管变化会改变价格波动、风险敞口或保证金压力 → 交易者使用杠杆来放大、对冲或管理风险。 |
| [市净率](pb-ratio.md) | 金融监管变化会影响企业盈利、估值折现率或投资者情绪 → 资金在股票中的配置变化 → 市净率出现上升、下降或结构切换。 |
| [系统性风险](systemic-risk.md) | 监管通过资本充足率、流动性要求、信息披露等限制过度冒险，降低单点风险向全系统扩散的概率。 |
