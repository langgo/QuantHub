# 市盈率

[← 返回目录](index.md)

## 官方解释
市盈率 PE 是股价与[每股收益](eps.md)的比值，常用于衡量市场愿意为每单位盈利支付多少价格。

## 小白解释
PE 可以理解为“按现在盈利几年能赚回股价”，但不能机械使用，高增长公司 PE 往往更高。

## 示例
股价 50 元、[每股收益](eps.md) 5 元，PE 为 10 倍。

## 与其它概念的关联作用
| 相关概念 | 详细关联与传导链路 |
|---|---|
| [折现率](discount-rate.md) | 折现率上升 → 未来盈利现值下降 → 市场愿意给的 PE 通常下降；成长股因盈利更靠未来，受影响更大。 |
| [盈利预期](earnings-expectation.md) | 市盈率变化会影响企业盈利、估值折现率或投资者情绪 → 资金在股票中的配置变化 → 盈利预期出现上升、下降或结构切换。 |
| [每股收益](eps.md) | PE=股价/EPS。股价不变时 EPS 上升会压低 PE；EPS 下滑会抬高 PE，说明估值可能变贵或盈利变差。 |
| [市值](market-capitalization.md) | 市盈率变化会影响企业盈利、估值折现率或投资者情绪 → 资金在股票中的配置变化 → 市值出现上升、下降或结构切换。 |
| [股票指数](stock-index.md) | 市盈率变化会影响企业盈利、估值折现率或投资者情绪 → 资金在股票中的配置变化 → 股票指数出现上升、下降或结构切换。 |
| [国债收益率](treasury-yield.md) | 市盈率变化会改变通胀、增长或信用风险预期 → 债券买卖力量变化 → 国债收益率随价格、收益率或风险补偿重新定价。 |
