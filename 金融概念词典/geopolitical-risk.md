# 地缘政治风险

[← 返回目录](index.md)

## 官方解释
地缘政治风险是战争、冲突、[制裁](sanction.md)、外交紧张等政治事件对经济、贸易、能源和金融市场造成的不确定性。

## 小白解释
地缘政治风险就是国家之间出事，市场不知道会影响多大，于是先避险。

## 示例
中东冲突升级后，[油价](oil-price.md)和[黄金](gold.md)上涨，股票[风险偏好](risk-appetite.md)下降。

## 与其它概念的关联作用
| 相关概念 | 详细关联与传导链路 |
|---|---|
| [黄金](gold.md) | 地缘冲突升级 → 市场不确定性上升 → 投资者买入黄金避险 → 金价可能上涨；若美元和实际利率大涨，会部分抵消。 |
| [天然气](natural-gas.md) | 地缘政治风险变化会改变全球需求、供给或库存预期 → 商品现货和期货价格重估 → 天然气随成本和风险溢价变化。 |
| [油价](oil-price.md) | 地缘冲突若威胁产油区或运输通道 → 市场预期供应中断 → 原油风险溢价上升 → 油价上涨。 |
| [OPEC+](opec.md) | 地缘政治风险变化会改变全球需求、供给或库存预期 → 商品现货和期货价格重估 → OPEC+随成本和风险溢价变化。 |
| [风险厌恶](risk-aversion.md) | 地缘政治风险变化会影响企业盈利、估值折现率或投资者情绪 → 资金在股票中的配置变化 → 风险厌恶出现上升、下降或结构切换。 |
| [避险资产](safe-haven-asset.md) | 地缘政治风险变化若增加不确定性、违约压力或市场恐慌 → 投资者转向防守 → 避险资产的重要性上升，并可能反过来影响资产价格。 |
| [制裁](sanction.md) | 地缘政治风险变化若增加不确定性、违约压力或市场恐慌 → 投资者转向防守 → 制裁的重要性上升，并可能反过来影响资产价格。 |
