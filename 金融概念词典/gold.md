# 黄金

[← 返回目录](index.md)

## 官方解释
黄金是贵金属和传统[避险资产](safe-haven-asset.md)，价格受[实际利率](real-interest-rate.md)、美元、[央行](central-bank.md)购金、[通胀预期](inflation-expectation.md)和风险情绪影响。

## 小白解释
黄金不生利息，所以当[实际利率](real-interest-rate.md)高时吸引力可能下降；但市场害怕时，黄金又可能被买来避险。

## 示例
美元走弱且[实际利率](real-interest-rate.md)下降时，黄金价格通常更容易上涨。

| [地缘政治风险](geopolitical-risk.md) | 地缘冲突升级 → 市场不确定性上升 → 投资者买入黄金避险 → 金价可能上涨；若美元和实际利率大涨，会部分抵消。 |
| [通胀预期](inflation-expectation.md) | 黄金变化会先影响需求、成本或预期 → 企业生产、居民消费和就业随之变化 → 最终反映到通胀预期等宏观数据上。 |
| [美国降息](rate-cut.md) | 降息降低实际利率和持有黄金的机会成本；若同时美元走弱或避险需求上升，黄金通常更容易上涨。 |
| [美国加息](rate-hike.md) | 加息推高名义利率，若通胀不同比例上升，实际利率上行 → 持有债券/现金的机会成本提高 → 不生息的黄金通常承压。 |
| [实际利率](real-interest-rate.md) | 加息推高名义利率，若通胀不同比例上升，实际利率上行 → 持有债券/现金的机会成本提高 → 不生息的黄金通常承压。 |
| [风险厌恶](risk-aversion.md) | 黄金变化会影响企业盈利、估值折现率或投资者情绪 → 资金在股票中的配置变化 → 风险厌恶出现上升、下降或结构切换。 |
| [避险资产](safe-haven-asset.md) | 黄金变化若增加不确定性、违约压力或市场恐慌 → 投资者转向防守 → 避险资产的重要性上升，并可能反过来影响资产价格。 |
| [国债收益率](treasury-yield.md) | 黄金变化会改变通胀、增长或信用风险预期 → 债券买卖力量变化 → 国债收益率随价格、收益率或风险补偿重新定价。 |
