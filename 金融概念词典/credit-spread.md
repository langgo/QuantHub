# 信用利差

[← 返回目录](index.md)

## 官方解释
信用利差是信用债收益率相对同期限无风险[国债收益率](treasury-yield.md)的额外补偿，用于反映信用风险和[流动性](liquidity.md)风险。

## 小白解释
公司借钱比政府更不安全，所以要多付一点利息。这多出来的部分就是信用利差。

## 示例
[经济衰退](recession.md)担忧升温时，高收益债信用利差扩大，说明市场要求更多风险补偿。

| [熊市](bear-market.md) | 信用利差变化会影响企业盈利、估值折现率或投资者情绪 → 资金在股票中的配置变化 → 熊市出现上升、下降或结构切换。 |
| [违约率](default-rate.md) | 违约率上升会让投资者要求更高补偿，信用利差扩大；信用利差先行扩大，也常表示市场预期未来违约率会上升。 |
| [金融监管](financial-regulation.md) | 信用利差变化若增加不确定性、违约压力或市场恐慌 → 投资者转向防守 → 金融监管的重要性上升，并可能反过来影响资产价格。 |

| [投资级债券](investment-grade-bond.md) | 信用利差变化会改变通胀、增长或信用风险预期 → 债券买卖力量变化 → 投资级债券随价格、收益率或风险补偿重新定价。 |
