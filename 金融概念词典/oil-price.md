# 油价

[← 返回目录](index.md)

## 官方解释
油价是原油市场价格，常以[布伦特原油](brent-crude.md)和 WTI 原油作为国际基准，受供需、库存、地缘政治和美元影响。

## 小白解释
油价就是原油多少钱。它影响汽油、运输、化工成本，也会影响[通胀](inflation.md)。

## 示例
[OPEC+](opec.md) 宣布减产后，油价上涨，市场可能上调[通胀预期](inflation-expectation.md)。

## 与其它概念的关联作用
| 相关概念 | 详细关联与传导链路 |
|---|---|
| [布伦特原油](brent-crude.md) | 布伦特是全球油价的主要参考。新闻说“国际油价上涨”时常看布伦特，它上涨会带动市场上调全球能源成本预期。 |
| [大宗商品指数](commodity-index.md) | 油价变化会改变全球需求、供给或库存预期 → 商品现货和期货价格重估 → 大宗商品指数随成本和风险溢价变化。 |
| [核心通胀](core-inflation.md) | 油价变化会先影响需求、成本或预期 → 企业生产、居民消费和就业随之变化 → 最终反映到核心通胀等宏观数据上。 |
| [CPI](cpi.md) | 油价变化会先影响需求、成本或预期 → 企业生产、居民消费和就业随之变化 → 最终反映到CPI等宏观数据上。 |
| [期货](futures.md) | 油价变化会改变价格波动、风险敞口或保证金压力 → 交易者使用期货来放大、对冲或管理风险。 |
| [地缘政治风险](geopolitical-risk.md) | 地缘冲突若威胁产油区或运输通道 → 市场预期供应中断 → 原油风险溢价上升 → 油价上涨。 |
| [通胀](inflation.md) | 油价上涨 → 汽油/柴油、航运空运、电力和化工原料成本上升 → 企业生产与物流成本上升 → 部分成本转嫁给消费者 → CPI 上行；若居民和企业开始预期“以后还会更贵”，通胀会更黏。 |
| [天然气](natural-gas.md) | 油价变化会改变全球需求、供给或库存预期 → 商品现货和期货价格重估 → 天然气随成本和风险溢价变化。 |
| [OPEC+](opec.md) | OPEC+ 减产或执行率提高 → 全球原油供给减少 → 库存下降预期增强 → 油价上升；增产或减产执行差则通常反向。 |
| [PPI](ppi.md) | 油价先影响企业端：原油/燃料/化工品涨价 → 工厂能源和原材料成本上升 → 出厂价提高 → PPI 上行；之后才可能继续传导到 CPI。 |
| [制裁](sanction.md) | 对产油国或能源企业制裁 → 可出口供应下降或结算运输受阻 → 市场上调供应风险溢价 → 油价上涨。 |
| [板块轮动](sector-rotation.md) | 油价上涨 → 能源企业收入和利润预期改善 → 资金可能流入能源板块；但高油价也会压制航空、运输等成本敏感行业。 |
| [滞胀](stagflation.md) | 油价冲击会同时推高成本和压低需求：能源变贵 → 通胀上行；居民和企业可支配收入被挤压 → 增长走弱，形成滞胀压力。 |
| [供需关系](supply-demand.md) | 需求增加或供给减少都会推高油价：出行/工业需求增加、产油国减产、库存下降 → 买方竞争更强 → 油价上涨；需求走弱或供给增加则反向。 |
| [WTI原油](wti-crude.md) | WTI 更反映北美原油市场。美国库存、炼厂开工和管道运输变化会先影响 WTI，再影响全球油价价差判断。 |
