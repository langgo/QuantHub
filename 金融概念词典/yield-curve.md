# 收益率曲线

[← 返回目录](index.md)

## 官方解释
收益率曲线展示同一发行主体不同期限债券的收益率水平，常用于观察市场对增长、[通胀](inflation.md)和政策利率的预期。

## 小白解释
它就是把 3 个月、2 年、10 年等不同期限的债券收益率连成一条线，看钱在短期和长期分别有多贵。

## 示例
正常情况下长期收益率高于短期；如果短期高于长期，就可能出现倒挂。

| [联邦基金目标利率](federal-funds-target-rate.md) | 收益率曲线变化会影响市场对政策松紧的判断 → 投资者重新评估央行是否加息、降息或投放流动性 → 联邦基金目标利率成为确认政策路径的关键变量。 |
| [经济衰退](recession.md) | 收益率曲线变化会先影响需求、成本或预期 → 企业生产、居民消费和就业随之变化 → 最终反映到经济衰退等宏观数据上。 |
| [期限利差](term-spread.md) | 收益率曲线变化会改变通胀、增长或信用风险预期 → 债券买卖力量变化 → 期限利差随价格、收益率或风险补偿重新定价。 |
| [国债收益率](treasury-yield.md) | 收益率曲线变化会改变通胀、增长或信用风险预期 → 债券买卖力量变化 → 国债收益率随价格、收益率或风险补偿重新定价。 |
| [收益率曲线倒挂](yield-curve-inversion.md) | 收益率曲线描述各期限利率；当短端高于长端时形成倒挂，说明市场认为当前政策利率高、未来增长和利率可能下行。 |
