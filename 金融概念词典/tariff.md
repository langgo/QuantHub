# 关税

[← 返回目录](index.md)

## 官方解释
关税是一国对进口或出口商品征收的税，常用于保护产业、增加财政收入或作为贸易谈判工具。

## 小白解释
关税就是商品过海关时多收的一笔税。税高了，进口商品可能更贵。

## 示例
美国提高某类进口商品关税后，相关商品售价可能上升，企业成本也可能增加。

## 与其它概念的关联作用
| 相关概念 | 详细关联与传导链路 |
|---|---|
| [财政政策](fiscal-policy.md) | 关税变化会改变通胀、增长或信用风险预期 → 债券买卖力量变化 → 财政政策随价格、收益率或风险补偿重新定价。 |
| [通胀](inflation.md) | 关税变化会先影响需求、成本或预期 → 企业生产、居民消费和就业随之变化 → 最终反映到通胀等宏观数据上。 |
| [供需关系](supply-demand.md) | 关税变化会改变全球需求、供给或库存预期 → 商品现货和期货价格重估 → 供需关系随成本和风险溢价变化。 |
| [贸易顺差与逆差](trade-balance.md) | 关税变化会影响利差、贸易收支或跨境资金方向 → 外汇供求改变 → 贸易顺差与逆差随之升值、贬值或波动扩大。 |
| [贸易摩擦](trade-war.md) | 贸易摩擦常通过关税落地：提高进口税 → 进口商品变贵、供应链重组 → 企业成本和消费者价格受到影响。 |
