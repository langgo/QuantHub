# 收益率曲线倒挂

[← 返回目录](index.md)

## 官方解释
[收益率曲线](yield-curve.md)倒挂指短期债券收益率高于长期债券收益率，常见形式是 2 年期收益率高于 10 年期收益率。

## 小白解释
倒挂就是短期借钱比长期更贵。市场常把它看作未来经济降温或降息的信号之一。

## 示例
美债 2 年期收益率 5%，10 年期 4%，说明市场认为短期利率高，但长期增长和[通胀](inflation.md)可能回落。

## 与其它概念的关联作用
| 相关概念 | 详细关联与传导链路 |
|---|---|
| [美国降息](rate-cut.md) | 收益率曲线倒挂变化会影响市场对政策松紧的判断 → 投资者重新评估央行是否加息、降息或投放流动性 → 美国降息成为确认政策路径的关键变量。 |
| [经济衰退](recession.md) | 收益率曲线倒挂变化会先影响需求、成本或预期 → 企业生产、居民消费和就业随之变化 → 最终反映到经济衰退等宏观数据上。 |
| [期限利差](term-spread.md) | 期限利差是倒挂的量化读数。10年-2年利差从正转负，表示曲线从正常斜率变为倒挂。 |
| [国债收益率](treasury-yield.md) | 收益率曲线倒挂变化会改变通胀、增长或信用风险预期 → 债券买卖力量变化 → 国债收益率随价格、收益率或风险补偿重新定价。 |
| [收益率曲线](yield-curve.md) | 收益率曲线描述各期限利率；当短端高于长端时形成倒挂，说明市场认为当前政策利率高、未来增长和利率可能下行。 |
