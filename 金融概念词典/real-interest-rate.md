# 实际利率

[← 返回目录](index.md)

## 官方解释
实际利率是剔除[通胀](inflation.md)影响后的利率，常近似为[名义利率](nominal-interest-rate.md)减去[通胀](inflation.md)率或[通胀预期](inflation-expectation.md)。

## 小白解释
[名义利率](nominal-interest-rate.md)看起来是你拿到的利息，实际利率看扣掉物价上涨后你真正赚多少。

## 示例
[名义利率](nominal-interest-rate.md) 5%，[通胀](inflation.md) 3%，实际利率约 2%。实际利率上升时，[黄金](gold.md)通常承压。

## 与其它概念的关联作用
| 相关概念 | 详细关联与传导链路 |
|---|---|
| [折现率](discount-rate.md) | 实际利率变化会影响企业盈利、估值折现率或投资者情绪 → 资金在股票中的配置变化 → 折现率出现上升、下降或结构切换。 |
| [黄金](gold.md) | 加息推高名义利率，若通胀不同比例上升，实际利率上行 → 持有债券/现金的机会成本提高 → 不生息的黄金通常承压。 |
| [通胀预期](inflation-expectation.md) | 实际利率变化会先影响需求、成本或预期 → 企业生产、居民消费和就业随之变化 → 最终反映到通胀预期等宏观数据上。 |
| [通胀](inflation.md) | 实际利率≈名义利率-通胀。通胀上升且名义利率不变 → 实际利率下降 → 持有现金/债券的真实回报变差。 |
| [名义利率](nominal-interest-rate.md) | 实际利率变化会改变通胀、增长或信用风险预期 → 债券买卖力量变化 → 名义利率随价格、收益率或风险补偿重新定价。 |
| [国债收益率](treasury-yield.md) | 实际利率变化会改变通胀、增长或信用风险预期 → 债券买卖力量变化 → 国债收益率随价格、收益率或风险补偿重新定价。 |
