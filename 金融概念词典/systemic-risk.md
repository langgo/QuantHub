# 系统性风险

[← 返回目录](index.md)

## 官方解释
系统性风险是单个机构、市场或事件的冲击通过金融网络传导，威胁整个金融体系稳定的风险。

## 小白解释
系统性风险不是一家公司的小问题，而是可能连锁传染，拖垮一大片金融机构或市场。

## 示例
大型金融机构倒闭引发交易对手恐慌，[信用利差](credit-spread.md)飙升，[央行](central-bank.md)提供紧急[流动性](liquidity.md)。

## 与其它概念的关联作用
| 相关概念 | 详细关联与传导链路 |
|---|---|
| [银行挤兑](bank-run.md) | 单家银行挤兑若引发“其他银行也不安全吗”的担忧 → 存款外流和同业互不信任扩散 → 系统性风险上升。 |
| [黑天鹅事件](black-swan.md) | 系统性风险变化若增加不确定性、违约压力或市场恐慌 → 投资者转向防守 → 黑天鹅事件的重要性上升，并可能反过来影响资产价格。 |
| [央行](central-bank.md) | 系统性风险变化会影响市场对政策松紧的判断 → 投资者重新评估央行是否加息、降息或投放流动性 → 央行成为确认政策路径的关键变量。 |
| [信用利差](credit-spread.md) | 系统性风险变化会改变通胀、增长或信用风险预期 → 债券买卖力量变化 → 信用利差随价格、收益率或风险补偿重新定价。 |
| [金融监管](financial-regulation.md) | 监管通过资本充足率、流动性要求、信息披露等限制过度冒险，降低单点风险向全系统扩散的概率。 |
| [流动性](liquidity.md) | 系统性风险变化会影响市场对政策松紧的判断 → 投资者重新评估央行是否加息、降息或投放流动性 → 流动性成为确认政策路径的关键变量。 |
