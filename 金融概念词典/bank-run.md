# 银行挤兑

[← 返回目录](index.md)

## 官方解释
银行挤兑是大量存款人在短时间内集中提款，导致银行[流动性](liquidity.md)压力急剧上升甚至破产的事件。

## 小白解释
银行把存款拿去放贷和投资，不会把所有现金都放柜台。大家同时来取钱，银行可能顶不住。

## 示例
某银行投资亏损消息引发恐慌，客户集中转出存款，监管机构介入稳定信心。

## 与其它概念的关联作用
| 相关概念 | 详细关联与传导链路 |
|---|---|
| [央行](central-bank.md) | 银行挤兑变化会影响市场对政策松紧的判断 → 投资者重新评估央行是否加息、降息或投放流动性 → 央行成为确认政策路径的关键变量。 |
| [金融监管](financial-regulation.md) | 银行挤兑变化若增加不确定性、违约压力或市场恐慌 → 投资者转向防守 → 金融监管的重要性上升，并可能反过来影响资产价格。 |
| [流动性](liquidity.md) | 存款人集中提款 → 银行需要快速筹现金 → 被迫卖资产或借短钱 → 流动性压力上升；若资产折价出售，会加剧亏损。 |
| [系统性风险](systemic-risk.md) | 单家银行挤兑若引发“其他银行也不安全吗”的担忧 → 存款外流和同业互不信任扩散 → 系统性风险上升。 |
| [美国国债](treasury-bond.md) | 银行挤兑变化会改变通胀、增长或信用风险预期 → 债券买卖力量变化 → 美国国债随价格、收益率或风险补偿重新定价。 |
