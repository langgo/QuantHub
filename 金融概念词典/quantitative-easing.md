# 量化宽松

[← 返回目录](index.md)

## 官方解释
量化宽松是[央行](central-bank.md)在政策利率接近低位时，通过购买国债或其他资产向金融体系投放基础货币的非常规[货币政策](monetary-policy.md)。

## 小白解释
QE 可以理解为[央行](central-bank.md)大规模买债，把钱注入市场，让金融体系更有钱、长期利率更低。

## 示例
金融危机后，美联储购买大量[美国国债](treasury-bond.md)和抵押贷款支持证券，压低长期利率，帮助市场恢复[流动性](liquidity.md)。

## 与其它概念的关联作用
| 相关概念 | 详细关联与传导链路 |
|---|---|
| [央行](central-bank.md) | 量化宽松变化会影响市场对政策松紧的判断 → 投资者重新评估央行是否加息、降息或投放流动性 → 央行成为确认政策路径的关键变量。 |
| [流动性](liquidity.md) | 央行买债 → 向卖方支付资金 → 银行准备金和市场可用资金增加 → 融资更顺、风险资产更容易获得买盘。 |
| [货币供应量](money-supply.md) | 量化宽松变化会影响市场对政策松紧的判断 → 投资者重新评估央行是否加息、降息或投放流动性 → 货币供应量成为确认政策路径的关键变量。 |
| [风险偏好](risk-appetite.md) | 量化宽松变化会影响企业盈利、估值折现率或投资者情绪 → 资金在股票中的配置变化 → 风险偏好出现上升、下降或结构切换。 |
| [美国国债](treasury-bond.md) | 量化宽松变化会改变通胀、增长或信用风险预期 → 债券买卖力量变化 → 美国国债随价格、收益率或风险补偿重新定价。 |
| [国债收益率](treasury-yield.md) | 央行买入国债 → 国债需求增加、价格上升 → 收益率下降；长期利率下降后，股票和房地产等资产估值可能受支撑。 |
