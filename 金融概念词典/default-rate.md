# 违约率

[← 返回目录](index.md)

## 官方解释
违约率是一定时期内未能按合同偿还本金或利息的债务主体占比，是衡量信用风险的重要指标。

## 小白解释
违约率就是借钱的人里有多少没按时还钱。它上升说明信用环境变差。

## 示例
[经济衰退](recession.md)时，现金流弱的企业更容易违约，高收益债违约率可能上升。

## 与其它概念的关联作用
| 相关概念 | 详细关联与传导链路 |
|---|---|
| [信用利差](credit-spread.md) | 违约率上升会让投资者要求更高补偿，信用利差扩大；信用利差先行扩大，也常表示市场预期未来违约率会上升。 |
| [金融监管](financial-regulation.md) | 违约率变化若增加不确定性、违约压力或市场恐慌 → 投资者转向防守 → 金融监管的重要性上升，并可能反过来影响资产价格。 |
| [高收益债券](high-yield-bond.md) | 违约率变化会改变通胀、增长或信用风险预期 → 债券买卖力量变化 → 高收益债券随价格、收益率或风险补偿重新定价。 |
| [投资级债券](investment-grade-bond.md) | 违约率变化会改变通胀、增长或信用风险预期 → 债券买卖力量变化 → 投资级债券随价格、收益率或风险补偿重新定价。 |
| [杠杆](leverage.md) | 违约率变化会改变价格波动、风险敞口或保证金压力 → 交易者使用杠杆来放大、对冲或管理风险。 |
| [经济衰退](recession.md) | 违约率变化会先影响需求、成本或预期 → 企业生产、居民消费和就业随之变化 → 最终反映到经济衰退等宏观数据上。 |
