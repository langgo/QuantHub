# PMI

[← 返回目录](index.md)

## 官方解释
PMI 即采购经理人指数，通过企业采购、订单、生产、库存等调查反映制造业或服务业景气度，通常以 50 为荣枯线。

## 小白解释
PMI 高于 50 通常说明扩张，低于 50 通常说明收缩。它像经济的体温计。

## 示例
制造业 PMI 跌到 48，说明制造业活动收缩，市场可能担心 [GDP](gdp.md) 放缓。

## 与其它概念的关联作用
| 相关概念 | 详细关联与传导链路 |
|---|---|
| [铜价](copper-price.md) | PMI 回升 → 制造业订单和开工改善 → 市场预期铜需求增加 → 铜价上行；PMI 跌破 50 时，铜价常被用来验证需求是否转弱。 |
| [GDP](gdp.md) | PMI变化会先影响需求、成本或预期 → 企业生产、居民消费和就业随之变化 → 最终反映到GDP等宏观数据上。 |
| [经济衰退](recession.md) | PMI 跌破 50 → 企业订单和生产收缩 → 收入与用工走弱 → GDP 下行压力增大，衰退概率上升。 |
| [股票指数](stock-index.md) | PMI变化会影响企业盈利、估值折现率或投资者情绪 → 资金在股票中的配置变化 → 股票指数出现上升、下降或结构切换。 |
| [供需关系](supply-demand.md) | PMI变化会改变全球需求、供给或库存预期 → 商品现货和期货价格重估 → 供需关系随成本和风险溢价变化。 |
