# 核心通胀

[← 返回目录](index.md)

## 官方解释
核心[通胀](inflation.md)通常指剔除食品和能源价格后的[通胀](inflation.md)指标，用于观察更稳定的物价趋势。

## 小白解释
食品和[油价](oil-price.md)波动大，所以把它们先拿掉，看剩下价格是不是也在涨。核心[通胀](inflation.md)高，说明涨价压力更黏。

## 示例
[油价](oil-price.md)短期大跌导致 [CPI](cpi.md) 回落，但核心 [CPI](cpi.md) 仍高，[央行](central-bank.md)可能不会急着降息。

| [CPI](cpi.md) | 核心通胀变化会先影响需求、成本或预期 → 企业生产、居民消费和就业随之变化 → 最终反映到CPI等宏观数据上。 |
| [通胀预期](inflation-expectation.md) | 核心通胀变化会先影响需求、成本或预期 → 企业生产、居民消费和就业随之变化 → 最终反映到通胀预期等宏观数据上。 |
| [通胀](inflation.md) | 核心通胀剔除食品和能源，更看长期趋势。若总通胀回落但核心通胀仍高，说明物价压力没有真正消退。 |
| [油价](oil-price.md) | 核心通胀变化会改变全球需求、供给或库存预期 → 商品现货和期货价格重估 → 油价随成本和风险溢价变化。 |
| [PPI](ppi.md) | 核心通胀变化会先影响需求、成本或预期 → 企业生产、居民消费和就业随之变化 → 最终反映到PPI等宏观数据上。 |
| [美国加息](rate-hike.md) | 核心通胀变化会影响市场对政策松紧的判断 → 投资者重新评估央行是否加息、降息或投放流动性 → 美国加息成为确认政策路径的关键变量。 |
| [薪资增速](wage-growth.md) | 工资上涨 → 居民消费能力增强，同时企业人工成本上升 → 服务价格更容易上涨 → 核心通胀可能更黏；若生产率同步提高，压力会小一些。 |
