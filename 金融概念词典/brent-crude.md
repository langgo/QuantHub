# 布伦特原油

[← 返回目录](index.md)

## 官方解释
布伦特原油是北海地区原[油价](oil-price.md)格基准，广泛用于欧洲、非洲和中东部分原油贸易定价。

## 小白解释
布伦特是全球最常看的国际[油价](oil-price.md)之一，新闻里说国际[油价](oil-price.md)很多时候指它。

## 示例
布伦特原油涨破 90 美元/桶，可能推高全球能源[通胀预期](inflation-expectation.md)。

## 与其它概念的关联作用
| 相关概念 | 详细关联与传导链路 |
|---|---|
| [美元指数](dxy.md) | 布伦特原油变化会影响利差、贸易收支或跨境资金方向 → 外汇供求改变 → 美元指数随之升值、贬值或波动扩大。 |
| [通胀](inflation.md) | 布伦特原油变化会先影响需求、成本或预期 → 企业生产、居民消费和就业随之变化 → 最终反映到通胀等宏观数据上。 |
| [油价](oil-price.md) | 布伦特是全球油价的主要参考。新闻说“国际油价上涨”时常看布伦特，它上涨会带动市场上调全球能源成本预期。 |
| [OPEC+](opec.md) | 布伦特原油变化会改变全球需求、供给或库存预期 → 商品现货和期货价格重估 → OPEC+随成本和风险溢价变化。 |
| [WTI原油](wti-crude.md) | 二者都是原油基准。全球供需决定共同方向，地区库存、管道运输、出口限制会影响价差：美国库存紧张时 WTI 可能相对更强。 |
