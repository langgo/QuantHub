# 回撤

[← 返回目录](index.md)

## 官方解释
回撤是资产净值或价格从阶段高点下跌到低点的幅度，最大回撤用于衡量历史最大亏损压力。

## 小白解释
回撤就是从最高点亏下来多少。它比平均收益更能告诉你持有过程难不难受。

## 示例
[基金净值](net-asset-value.md)从 1.50 跌到 1.20，回撤为 20%。

| 相关概念 | 详细关联与传导链路 |
|---|---|
| [熊市](bear-market.md) | 回撤变化会影响企业盈利、估值折现率或投资者情绪 → 资金在股票中的配置变化 → 熊市出现上升、下降或结构切换。 |
| [基金净值](net-asset-value.md) | 回撤根据基金净值路径计算：从净值高点跌到后续低点的比例越大，投资者承受的亏损压力越高。 |
| [风险厌恶](risk-aversion.md) | 回撤变化会影响企业盈利、估值折现率或投资者情绪 → 资金在股票中的配置变化 → 风险厌恶出现上升、下降或结构切换。 |
| [夏普比率](sharpe-ratio.md) | 回撤变化会改变组合收益、风险或资产间联动 → 投资者通过夏普比率评估配置是否仍合适。 |
| [波动率](volatility.md) | 回撤变化会改变价格波动、风险敞口或保证金压力 → 交易者使用波动率来放大、对冲或管理风险。 |
