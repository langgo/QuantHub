# 量化交易调研

> 调研时间：2026-08-21  
> 信息来源：网页搜索与公开资料整理。本文用于学习和研究，不构成投资建议。

## 1. 一句话理解

量化交易是把交易想法写成可验证的规则，用数据测试、用程序执行、用风控约束，而不是靠临场感觉买卖。

更完整地说：

> 量化交易 = 数据 → 信号 → 策略 → 回测 → 风控 → 执行 → 复盘迭代。

如果一个策略只在历史数据里看起来赚钱，但没有考虑交易成本、滑点、容量、过拟合、数据泄漏和实盘执行，它还不能算成熟的量化交易系统。

---

## 2. 官方解释

量化交易通常指利用数学模型、统计方法和计算机程序，从历史数据和实时数据中寻找具有统计优势的交易信号，并按照预设规则自动或半自动完成投资决策、组合构建、下单执行和风险管理。

公开资料中常见定义强调几个关键词：

- **数据驱动**：依赖行情、财务、宏观、新闻、另类数据等输入。
- **模型化**：把投资逻辑转成数学、统计或机器学习模型。
- **系统化**：用规则而不是情绪做决策。
- **可回测**：在历史数据中验证策略表现。
- **可执行**：考虑真实交易成本、滑点、成交和容量。
- **可风控**：对仓位、回撤、杠杆、行业暴露、因子暴露设置约束。

---

## 3. 小白解释

普通主观交易可能是：

> 我觉得这个股票要涨，所以我买。

量化交易更像是：

> 如果满足 A、B、C 三个条件，就买；如果满足 D 条件，就卖。  
> 这个规则先拿过去很多年的数据测试，如果长期看有稳定优势，再考虑真实交易。

例如一个最简单的双均线策略：

- 5 日均线上穿 20 日均线：买入；
- 5 日均线下穿 20 日均线：卖出；
- 每次最多买入总资金的 95%；
- 加入手续费、印花税、最小交易单位；
- 回测后看收益率、最大回撤、夏普比率等指标。

这不代表双均线策略一定赚钱。它只是一个入门例子，帮助理解完整流程。

## 4. 量化交易的核心闭环

### 4.1 数据 Data

数据是量化交易的原材料。

常见数据包括：

| 数据类型 | 示例 | 用途 |
|---|---|---|
| 行情数据 | 开盘价、收盘价、最高价、最低价、成交量、盘口 | 计算趋势、波动、成交活跃度 |
| 财务数据 | 收入、利润、现金流、ROE、PE、PB | 基本面因子、价值投资模型 |
| 宏观数据 | 利率、通胀、汇率、PMI、就业 | 宏观择时、资产配置 |
| 新闻公告 | 公司公告、财报、政策、新闻 | 事件驱动、情绪分析 |
| 另类数据 | 搜索指数、卫星图像、招聘数据、舆情 | 寻找非传统信号 |

数据处理要注意：

- 缺失值；
- 异常值；
- 复权价格；
- 停牌；
- 涨跌停；
- 指数成分变更；
- 财报发布时间；
- 数据是否在当时已经可获得。

最后一点很关键：如果回测用了当时还不知道的数据，就是 **未来函数 / look-ahead bias**。

### 4.2 信号 Signal

信号是策略判断买卖的依据。

常见信号：

| 信号类型 | 示例 |
|---|---|
| 趋势信号 | 均线突破、价格创新高、动量因子 |
| 均值回归信号 | 超跌反弹、配对交易、价差回归 |
| 价值信号 | 低 PE、低 PB、高股息率 |
| 质量信号 | 高 ROE、低负债率、现金流稳定 |
| 成长信号 | 收入增速、利润增速、盈利预期上调 |
| 情绪信号 | 新闻情绪、社媒热度、资金流向 |
| 微观结构信号 | 盘口不平衡、订单簿变化、成交冲击 |

一个好信号不只是“历史上有效”，还要有合理解释：为什么这个信号未来可能继续有效？

### 4.3 策略 Strategy

策略是把信号变成交易规则。

一个策略至少要回答：

1. 买什么？
2. 什么时候买？
3. 买多少？
4. 什么时候卖？
5. 最大亏损能接受多少？
6. 交易成本后还赚钱吗？
7. 市场环境变化后还有效吗？

### 4.4 回测 Backtesting

回测是在历史数据上模拟策略过去会如何表现。

严谨回测需要：

- 只使用当时可获得的信息；
- 加入手续费、印花税、点差、滑点；
- 模拟真实成交价格，而不是理想价格；
- 处理停牌、涨跌停、成交量不足；
- 维护现金、仓位、保证金；
- 使用样本外测试和滚动测试；
- 对不同市场环境分段评估。

公开资料反复强调：回测是必要的，但也是最危险的环节，因为最容易出现过拟合。

### 4.5 风控 Risk Control

风控决定策略能不能活下来。

常见风控维度：

| 风控项 | 说明 |
|---|---|
| 单票仓位限制 | 防止押注单一股票 |
| 行业仓位限制 | 防止过度集中在一个行业 |
| 最大回撤限制 | 回撤超过阈值时减仓或停机 |
| 杠杆限制 | 控制融资、期货、期权带来的放大风险 |
| 流动性限制 | 成交量太小的标的不交易或少交易 |
| 因子暴露限制 | 控制市值、风格、行业、Beta 暴露 |
| 止损 / 熔断 | 极端行情下保护账户 |
| Kill Switch | 系统异常或风险超限时自动停止交易 |

### 4.6 执行 Execution

执行是把策略信号变成真实订单。

慢策略可能只需要每天收盘后调仓；高频策略则需要考虑撮合、延迟、排队位置、服务器位置等。

常见执行算法：

| 执行方式 | 说明 |
|---|---|
| 市价单 | 立刻成交，但可能滑点较大 |
| 限价单 | 控制价格，但可能成交不了 |
| VWAP | 按成交量加权平均价格拆单 |
| TWAP | 按时间均匀拆单 |
| Implementation Shortfall | 尽量降低从决策到成交的总成本 |

## 5. 常见量化策略类型

### 5.1 趋势跟踪

核心想法：涨的可能继续涨，跌的可能继续跌。

常见规则：

- 均线突破；
- 动量排序；
- 价格创 N 日新高；
- CTA 商品期货趋势跟踪。

优点：能抓住大趋势。  
缺点：震荡市容易反复止损。

### 5.2 均值回归

核心想法：价格偏离正常水平后，未来可能回到均值。

例子：

- 超跌反弹；
- 配对交易；
- 价差套利；
- 统计套利。

优点：在震荡市场中可能有效。  
缺点：如果趋势真的变了，“便宜”可能变得更便宜。

### 5.3 多因子选股

核心想法：用多个因子给股票打分，买入综合得分高的股票。

常见因子：

| 因子 | 含义 |
|---|---|
| 价值 | 低 PE、低 PB、高股息 |
| 质量 | 高 ROE、低负债、现金流好 |
| 成长 | 收入和利润增长快 |
| 动量 | 过去一段时间表现强 |
| 低波动 | 波动较低、回撤较小 |
| 小市值 | 市值较小的公司 |

多因子策略要注意因子拥挤、因子失效和行业中性。

### 5.4 套利策略

套利策略寻找两个相关资产之间的价格偏差。

例子：

- ETF 与成分股套利；
- 股指期货与现货套利；
- 可转债套利；
- 期现套利；
- 跨市场套利。

优点：逻辑清晰。  
缺点：机会可能短暂，交易成本和执行速度很重要。

### 5.5 做市策略

做市商同时挂买单和卖单，赚取买卖价差。

例子：

> 买价 100.00，卖价 100.05。  
> 如果不断低买高卖，就能赚价差。

但做市不是无风险：如果市场单边大跌，做市商可能买入越来越多下跌资产。

### 5.6 事件驱动策略

利用特定事件导致的价格变化。

事件包括：

- 财报发布；
- 分红送转；
- 并购重组；
- 指数调仓；
- 政策变化；
- 业绩预告。

### 5.7 机器学习策略

用机器学习模型从大量特征中预测未来收益、波动或风险。

常见模型：

- 线性回归；
- 随机森林；
- XGBoost / LightGBM；
- 神经网络；
- 时间序列模型；
- 强化学习。

机器学习不等于更赚钱。金融数据噪声大、非平稳、样本少，过拟合风险很高。

## 6. 回测常见陷阱

### 6.1 未来函数 Look-ahead Bias

使用了交易当时还不知道的信息。

例子：

- 用当天收盘价决定当天收盘买入；
- 用后来修正后的财务数据做历史回测；
- 提前知道指数成分股调整。

### 6.2 幸存者偏差 Survivorship Bias

只用现在还活着的股票回测，忽略已经退市、破产、被并购的股票。

结果：回测收益被高估，因为最差的股票被删除了。

### 6.3 过拟合 Overfitting

策略把历史噪声当成规律。

典型表现：

- 参数很多；
- 规则很复杂；
- 换一个时间段就失效；
- 样本外表现明显变差；
- 对小参数变化极其敏感。

防范方法：

- 保持策略简单；
- 要有经济逻辑；
- 做样本外测试；
- 做滚动测试；
- 减少参数搜索；
- 不要只挑最好看的回测结果。

### 6.4 忽略交易成本

真实交易成本包括：

- 佣金；
- 印花税；
- 买卖价差；
- 滑点；
- 市场冲击；
- 融券成本；
- 资金成本。

高换手策略尤其怕交易成本。一个毛收益看起来不错的策略，加上成本后可能完全不赚钱。

### 6.5 容量问题

策略小资金有效，不代表大资金也有效。

原因：

- 小票成交量不足；
- 大单会冲击价格；
- 进出场需要更长时间；
- 越多人使用同类策略，超额收益越容易消失。

## 7. 常用评价指标

| 指标 | 含义 | 小白解释 |
|---|---|---|
| 累计收益率 | 策略总收益 | 最后赚了多少 |
| 年化收益率 | 折算成每年的收益 | 方便和其他投资比较 |
| 最大回撤 | 从高点跌到低点的最大跌幅 | 最难受时亏了多少 |
| 夏普比率 | 单位波动获得的超额收益 | 冒同样风险赚得值不值 |
| 卡玛比率 | 年化收益 / 最大回撤 | 收益和最大亏损的性价比 |
| 胜率 | 盈利交易占比 | 十次交易里几次赚钱 |
| 盈亏比 | 平均盈利 / 平均亏损 | 赚一次能抵几次亏 |
| 换手率 | 仓位变化频率 | 交易有多频繁 |
| 信息比率 | 相对基准的超额收益质量 | 跑赢指数是否稳定 |
| Beta | 对市场波动的敏感度 | 大盘涨跌时它跟得多紧 |
| Alpha | 扣除市场影响后的超额收益 | 真正靠策略赚到的部分 |

不要只看单一指标。高收益但最大回撤 80%，对多数人没有意义。

## 9. 从 0 到 1 的学习路线

### 阶段 1：金融基础

先理解：

- 股票、债券、期货、期权；
- 收益率、波动率、回撤；
- Alpha、Beta；
- 市盈率、市净率、ROE；
- 交易成本、滑点、流动性。

### 阶段 2：Python 数据分析

掌握：

- pandas；
- NumPy；
- 时间序列；
- 数据清洗；
- 可视化；
- 基础统计。

### 阶段 3：写第一个策略

建议从双均线开始：

1. 获取历史行情；
2. 计算 MA5 和 MA20；
3. 生成买卖信号；
4. 加入手续费；
5. 计算收益和最大回撤；
6. 画资金曲线。

重点不是让它赚钱，而是跑通流程。

### 阶段 4：做严谨回测

补上：

- 复权；
- 停牌；
- 涨跌停；
- 成交量限制；
- 滑点；
- 样本外测试；
- 参数敏感性分析。

### 阶段 5：研究策略

可以尝试：

- 动量策略；
- 均值回归；
- 多因子选股；
- 行业轮动；
- 配对交易；
- 事件驱动。

### 阶段 6：模拟盘和实盘

实盘前至少要做：

- 模拟盘；
- 小资金验证；
- 日志记录；
- 异常报警；
- 风控开关；
- 手动接管方案。

## 10. 一个最小可行的量化研究模板

```text
1. 提出假设
   例如：过去 20 日涨幅高的股票，未来 5 日仍有惯性。

2. 准备数据
   获取股票池、行情、复权价格、停牌信息。

3. 构造信号
   计算 20 日动量，并按分位数排序。

4. 组合构建
   买入排名前 20% 的股票，等权持有。

5. 回测
   加入手续费、滑点、调仓频率、涨跌停限制。

6. 评价
   看年化收益、最大回撤、夏普、换手率、分年度表现。

7. 稳健性测试
   换时间段、换参数、换股票池、加入成本压力测试。

8. 模拟盘
   不投入真实资金，观察实时表现。

9. 小资金实盘
   验证交易链路、滑点、成交和心理压力。

10. 持续复盘
   记录每次信号、成交、偏差和风险事件。
```

## 11. 量化交易常见误区

### 误区 1：回测赚钱 = 实盘赚钱

错误。回测可能有未来函数、幸存者偏差、过拟合、成本低估。

### 误区 2：模型越复杂越好

错误。金融市场噪声大，复杂模型更容易过拟合。

### 误区 3：机器学习一定比传统策略强

错误。机器学习需要高质量数据、严格验证和稳定特征。很多简单策略更稳健。

### 误区 4：只看收益率

错误。最大回撤、波动、换手、容量和尾部风险同样重要。

### 误区 5：忽略市场制度

不同市场规则不同：

- A 股有 T+1、涨跌停、印花税；
- 美股有做空和盘前盘后；
- 期货有保证金和强平；
- 加密货币 7×24 小时交易。

策略必须适配市场制度。

## 12. 适合继续研究的问题

1. 一个因子为什么有效？是风险补偿、行为偏差，还是数据挖掘？
2. 策略收益来自 Alpha，还是只是承担了 Beta？
3. 策略在不同市场环境下表现如何？
4. 加入真实成本后是否还赚钱？
5. 策略容量有多大？
6. 如果连续亏损 3 个月，应该停用还是继续？
7. 策略失效的判断标准是什么？
8. 实盘执行和回测假设差距有多大？

## 14. 最后提醒

量化交易的难点不是写出一个能回测赚钱的策略，而是证明它不是错觉，并让它在真实市场里活下来。

最小正确路径是：

> 简单假设 → 干净数据 → 无未来函数回测 → 加真实成本 → 样本外验证 → 小资金实盘 → 长期复盘。
