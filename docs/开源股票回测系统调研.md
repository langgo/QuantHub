# 开源股票回测系统调研：从手写策略到 AI 生成策略

> 调研时间：2026-08-28  
> 目标问题：是否存在开源股票回测系统，支持手写脚本、AI 生成脚本、选择策略或因子，并能基于单只股票或股票池，在指定周期内回测和可视化结果。  
> 说明：本文用于技术选型和产品设计参考，不构成投资建议。

---

## 1. 结论先行

有开源项目能覆盖大部分需求，但目前很少有一个项目同时做到：

```text
AI 自然语言写策略 + 股票数据下载 + 手写脚本 + 因子选择 + 股票池回测 + 完整可视化 + 中文 A 股友好
```

更现实的方案是组合现有开源组件：

```text
数据层：akshare / tushare / yfinance / OpenBB
回测层：vectorbt / backtesting.py / Backtrader / PyBroker / Qlib
可视化：Plotly / Streamlit / QuantStats
AI 策略生成：LLM 生成受限的 Python 信号函数或策略 JSON，而不是直接执行任意代码
```

如果要快速做一个可用产品，推荐第一版采用：

```text
Streamlit + vectorbt + akshare/yfinance + Plotly + QuantStats
```

原因：

- `vectorbt` 适合股票池、参数扫描、因子回测和可视化；
- `akshare` 覆盖大量 A 股、基金、期货、宏观数据；
- `yfinance` 适合美股和 ETF；
- `Streamlit` 做交互页面最快；
- AI 可以生成 pandas/vectorbt 风格的信号函数，接入成本低。

## 2. 用户需求拆解

用户想要的系统，本质上包含 6 个能力：

| 能力 | 说明 |
|---|---|
| 数据获取 | 按股票、股票池、市场、周期下载历史行情和基础数据 |
| 策略表达 | 支持手写 Python 脚本、模板策略、因子组合，甚至 AI 自然语言生成策略 |
| 回测引擎 | 在指定时间区间内模拟交易，计算收益、回撤、交易记录、持仓 |
| 股票池支持 | 支持单只股票、多只股票、指数成分股、自定义股票池 |
| 结果分析 | 输出年化收益、最大回撤、夏普、胜率、盈亏比、换手率等指标 |
| 可视化 | 展示 K 线、买卖点、资金曲线、回撤曲线、持仓、交易明细、参数热力图 |

如果再加上 AI，则还需要：

| AI 能力 | 说明 |
|---|---|
| 自然语言解析 | 把“回测茅台 20/60 日均线策略”解析成结构化参数 |
| 策略代码生成 | 生成受限 Python 函数或策略配置 |
| 代码校验 | 检查字段、函数签名、禁止危险操作 |
| 自动修复 | 策略代码报错后，把错误反馈给 AI 修改 |
| 报告解释 | 用自然语言解释回测指标和风险 |

## 3. 主流开源回测框架

### 3.1 vectorbt

项目地址：

- https://github.com/polakowo/vectorbt
- https://vectorbt.dev/

`vectorbt` 是一个基于 pandas、NumPy、Numba 的向量化回测和研究框架。它的核心特点是把大量策略参数、多个股票、多组信号放进数组里一次性计算，非常适合批量实验。

官方 README 强调它可以同时运行大量配置，支持组合回测、交易分析、回撤分析、QuantStats 集成，以及 Plotly/Jupyter 交互式可视化。

适合场景：

| 场景 | 适合度 |
|---|---|
| 单股票策略回测 | 高 |
| 多股票股票池回测 | 高 |
| 因子排序 / 动量策略 | 高 |
| 参数扫描 / 热力图 | 很高 |
| AI 生成信号函数 | 高 |
| 高频逐笔撮合 | 低 |
| 复杂订单生命周期 | 中低 |

示例：

```python
import vectorbt as vbt

price = vbt.YFData.download("AAPL", start="2020-01-01").get("Close")

fast_ma = vbt.MA.run(price, 10)
slow_ma = vbt.MA.run(price, 30)

entries = fast_ma.ma_crossed_above(slow_ma)
exits = fast_ma.ma_crossed_below(slow_ma)

pf = vbt.Portfolio.from_signals(price, entries, exits, init_cash=100_000)
print(pf.stats())
pf.plot().show()
```

优点：

- 非常适合研究、因子和批量参数实验；
- 可视化能力强；
- pandas 风格，AI 很容易生成代码；
- 多股票、多参数回测效率高。

缺点：

- 事件驱动和订单细节不如 Backtrader、LEAN、NautilusTrader；
- 对真实撮合、盘口、复杂委托的模拟不是主战场。

结论：

> 做“选股票、选周期、选策略/因子、快速回测、可视化”的产品，`vectorbt` 是最推荐的底层引擎。

### 3.2 backtesting.py

项目地址：

- https://github.com/kernc/backtesting.py
- https://kernc.github.io/backtesting.py/

`backtesting.py` 是轻量级 Python 回测框架。它的 API 很简单，策略通过继承 `Strategy` 类实现，适合教学、单股票策略、快速验证交易逻辑。

官方文档强调它支持：

- 内置优化器；
- 交互式可视化；
- 向量化或事件式回测；
- 可组合策略；
- 止损、止盈、仓位管理等高层 API。

适合场景：

| 场景 | 适合度 |
|---|---|
| 单股票策略 | 很高 |
| 手写策略 | 很高 |
| AI 生成策略类 | 高 |
| 教学和 Demo | 很高 |
| 股票池因子回测 | 中低 |
| 大规模参数扫描 | 中 |

示例：

```python
from backtesting import Backtest, Strategy
from backtesting.lib import crossover
from backtesting.test import SMA, GOOG

class SmaCross(Strategy):
    n1 = 10
    n2 = 30

    def init(self):
        close = self.data.Close
        self.sma1 = self.I(SMA, close, self.n1)
        self.sma2 = self.I(SMA, close, self.n2)

    def next(self):
        if crossover(self.sma1, self.sma2):
            self.buy()
        elif crossover(self.sma2, self.sma1):
            self.sell()

bt = Backtest(GOOG, SmaCross, cash=100_000)
stats = bt.run()
bt.plot()
```

优点：

- 简单；
- 策略代码短；
- 很适合 AI 生成策略脚本；
- 内置图表够用。

缺点：

- 股票池、多资产、因子研究能力不如 vectorbt / Qlib；
- 做成复杂平台后需要自己补不少功能。

结论：

> 如果第一版只做“单只股票 + 手写/AI 策略 + 可视化”，`backtesting.py` 是最快选择。

### 3.3 Backtrader

项目地址：

- https://github.com/backtrader/backtrader
- https://www.backtrader.com/

`Backtrader` 是老牌 Python 事件驱动回测框架。它支持回测和实盘，官方 README 提到支持 Interactive Brokers、Oanda 等实盘或数据接口，也支持完整图表展示。

适合场景：

| 场景 | 适合度 |
|---|---|
| 事件驱动回测 | 很高 |
| 多周期策略 | 高 |
| 多数据源 | 高 |
| 手写复杂策略 | 高 |
| AI 生成简单策略 | 中 |
| 快速做 Web 产品 | 中低 |

优点：

- 成熟、资料多；
- 策略、数据、经纪商、订单模型完整；
- 更接近真实交易过程。

缺点：

- 代码模板偏长；
- 框架较老；
- 可视化体验不如现代 Plotly / Streamlit 组合；
- AI 生成策略时上下文和样板代码更多。

结论：

> 如果重视订单、撮合、多周期和接近实盘的流程，可以选 Backtrader；如果只是快速搭建研究型产品，优先级低于 vectorbt。

- https://github.com/quantopian/zipline

`Zipline` 是 Quantopian 时代的知名开源回测框架，`zipline-reloaded` 是后续维护版本。它偏美股研究，API 风格接近机构回测系统。

适合场景：

| 场景 | 适合度 |
|---|---|
| 美股历史回测 | 高 |
| Pipeline 因子研究 | 中高 |

- 经典；
- 回测流程严谨；

> 适合了解，不建议作为新项目 MVP 的首选。

### 3.6 PyBroker

项目地址：

- https://www.pybroker.com/
- https://github.com/edtechre/pybroker

`PyBroker` 是面向机器学习策略的 Python 算法交易框架。官方介绍中强调：

- 使用 NumPy 和 Numba 的快速回测引擎；
- 支持多标的执行交易规则；
- 支持日、周、月等多周期；
- 可接 Alpaca、Yahoo Finance、AKShare 或自定义数据源；
- 支持 Walkforward Analysis；
- 支持参数优化和交易指标。

适合场景：

| 场景 | 适合度 |
|---|---|
| 机器学习策略 | 高 |
| 多股票策略 | 高 |
| Walk-forward 验证 | 很高 |
| AI 生成规则 | 中高 |
| A 股数据 | 中高，依赖 AKShare |
| 成熟生态 | 中 |

优点：

- 比 Backtrader 更现代；
- ML 友好；
- 数据源集成相对直接。

缺点：

- 社区和资料规模不如 Backtrader/vectorbt；
- 可视化和产品化仍要自己补。

结论：

> 如果重点是“机器学习策略 + walk-forward 验证”，PyBroker 是值得评估的候选。

### 3.7 RQAlpha

项目地址：

- https://github.com/ricequant/rqalpha

`RQAlpha` 是米筐开源的程序化交易回测框架。README 中说明它从数据获取、算法交易、回测引擎、实盘模拟、实盘交易到数据分析，提供全套解决方案；但项目声明仅限非商业使用。

它内置 Mod 机制，例如：

- `sys_accounts`：股票、期货账户和持仓模型；
- `sys_analyser`：记录下单、成交、组合、持仓，计算风险指标，并输出 CSV、plot 图表等分析结果；
- `sys_risk`：事前风控；
- `sys_simulation`：模拟撮合和回测事件源；
- `sys_transaction_cost`：股票、期货交易税费。

适合场景：

| 场景 | 适合度 |
|---|---|
| A 股回测 | 高 |
| 国内期货 | 高 |
| 米筐生态 | 很高 |
| 非商业学习 | 高 |
| 商业化产品 | 低，需注意授权 |
| AI 生成策略 | 中 |

优点：

- 中文生态友好；
- A 股、期货概念支持较好；
- 回测分析模块比较完整。

缺点：

- 授权限制需要特别注意；
- 如果脱离米筐数据生态，需要自己处理数据源。

结论：

> 做中文学习型或内部研究可以看；商业产品要谨慎处理授权。

### 6.2 数据标准格式

无论数据来自哪里，先统一成一张表：

```text
date, symbol, open, high, low, close, volume, amount, adj_close
```

如果支持因子，再加：

```text
pe, pb, roe, market_cap, turnover, industry, is_st, is_suspended
```

统一数据格式比一开始接十个数据源更重要。

## 7. 策略表达方式设计

### 7.1 模板策略

最安全，适合普通用户。

```text
策略：双均线
参数：fast_window=20, slow_window=60
买入：MA20 上穿 MA60
卖出：MA20 下穿 MA60
```

常见模板：

| 策略 | 参数 |
|---|---|
| 双均线 | fast_window, slow_window |
| RSI 超卖反弹 | rsi_window, buy_threshold, sell_threshold |
| MACD 金叉 | fast, slow, signal |
| 布林带突破 | window, std |
| 动量排序 | lookback, top_n, rebalance_freq |
| 低估值因子 | PE/PB 分位数、ROE 阈值 |
| 多因子打分 | 因子权重、行业中性、调仓频率 |

### 7.2 手写 Python 策略函数

给高级用户一个固定函数签名：

```python
def generate_signals(data, params):
    close = data["close"]
    fast = close.rolling(params["fast"]).mean()
    slow = close.rolling(params["slow"]).mean()

    entries = fast > slow
    exits = fast < slow
    return entries, exits
```

不要让用户随便改整个回测引擎，只允许生成信号。

### 7.3 AI 生成策略

用户输入：

```text
帮我回测贵州茅台 2020 到 2024 年的 20/60 日均线策略，手续费万三。
```

AI 先生成结构化配置：

```json
{
  "symbols": ["600519.SH"],
  "start": "2020-01-01",
  "end": "2024-12-31",
  "strategy": "ma_cross",
  "params": {
    "fast": 20,
    "slow": 60
  },
  "fees": 0.0003
}
```

只有模板无法覆盖时，再让 AI 生成受限函数：

```python
def generate_signals(data, params):
    close = data["close"]
    ma20 = close.rolling(20).mean()
    ma60 = close.rolling(60).mean()
    entries = ma20 > ma60
    exits = ma20 < ma60
    return entries, exits
```

## 8. AI 生成代码的安全边界

不要直接执行 AI 生成的任意 Python。最低限度要做：

1. 固定函数签名；
2. 禁止 `import os`、`subprocess`、`socket`、`open`、`eval`、`exec`；
3. 禁止访问文件系统和网络；
4. 限制运行时间；
5. 限制内存；
6. 只暴露 pandas、numpy、技术指标函数；
7. 执行前做 AST 检查；
8. 回测失败时返回错误给 AI 修复，但不要放宽权限。

更懒也更安全的方案：

```text
自然语言 → JSON 策略配置 → 模板策略执行
```

只有当模板覆盖不了，再进入“AI 生成代码”。

## 9. 可视化结果应该包含什么

最小必备：

| 图表 / 表格 | 说明 |
|---|---|
| K 线 + 买卖点 | 看策略是否按预期交易 |
| 净值曲线 | 策略资金变化 |
| 基准对比 | 和沪深 300、标普 500、纳指等比较 |
| 回撤曲线 | 展示最大亏损过程 |
| 月度收益热力图 | 看收益是否集中在少数月份 |
| 持仓变化 | 多股票策略必须有 |
| 交易明细 | 每笔买卖、价格、收益、手续费 |
| 指标表 | 年化收益、最大回撤、夏普、胜率、换手率 |
| 参数热力图 | 比如 MA fast/slow 参数网格 |
| 因子分组收益 | 多因子策略需要 |

第一版不必做所有图，最少做：

```text
净值曲线 + 回撤曲线 + 交易点 + 指标表 + 交易明细
```

## 10. 推荐 MVP 实现路线

### 阶段 1：单股票回测

目标：跑通最小闭环。

功能：

- 输入股票代码；
- 输入开始、结束日期；
- 选择策略模板：双均线 / RSI；
- 使用 `yfinance` 或 `akshare` 下载数据；
- 使用 `vectorbt` 回测；
- 展示净值曲线、回撤、指标。

技术栈：

```text
streamlit
vectorbt
pandas
akshare
yfinance
plotly
```

### 阶段 2：股票池和因子

功能：

- 支持多个股票；
- 支持动量排序；
- 支持等权组合；
- 支持定期调仓；
- 展示持仓权重和分年度表现。

### 阶段 3：AI 策略助手

功能：

- 自然语言解析成 JSON；
- 如果命中模板，直接跑模板；
- 如果没有命中模板，AI 生成 `generate_signals` 函数；
- AST 安全检查；
- 失败自动修复一次；
- 生成回测报告解释。

### 阶段 4：报告导出

功能：

- 导出 HTML；
- 导出 Markdown；
- 保存策略配置；
- 保存回测结果；
- 可复现实验。

## 11. 不建议第一版做的事

这些东西很诱人，但第一版可以先跳过：

| 功能 | 为什么先跳过 |
|---|---|
| 实盘交易 | 风险高，监管和账户接入复杂 |
| 高频 Tick 回测 | 数据、性能、撮合都复杂 |
| 期权策略 | 定价、希腊值、保证金复杂 |
| 任意 Python 沙箱 | 安全成本高 |
| 十几个数据源 | 数据格式统一会拖慢进度 |
| 自研回测引擎 | 先用 vectorbt，别重复造轮子 |
| 复杂权限系统 | 单机 MVP 不需要 |
| 完整因子平台 | 先做 3-5 个典型因子 |

## 12. 最终推荐

如果目标是快速做一个开源股票回测系统，支持 AI/手写/模板策略，建议：

```text
第一选择：vectorbt + Streamlit + akshare/yfinance + Plotly
第二选择：backtesting.py + Streamlit，用于更简单的单股票 MVP
进阶选择：Qlib / PyBroker，用于 AI 多因子或机器学习研究
工业级选择：LEAN / NautilusTrader，但不适合作为第一版
```

最小产品闭环：

```text
用户输入自然语言或选择模板
    ↓
解析股票、周期、策略参数
    ↓
下载并清洗数据
    ↓
生成 entries/exits 或 target weights
    ↓
vectorbt 回测
    ↓
展示图表、指标、交易记录
    ↓
AI 生成解释和风险提示
```

一句话建议：

> 不要一开始找“大而全的 AI 量化平台”。先用 `vectorbt` 把股票、周期、策略、回测、可视化跑通；AI 只负责生成受限策略配置或信号函数。这样最短路径能满足需求，也最容易扩展。
